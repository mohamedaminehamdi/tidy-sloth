Install on your Mac

One line sets up everything. You only do this once.

curl -fsSL https://mohamedaminehamdi.github.io/tidy-sloth/install.sh | sh
  1. Open Terminal (⌘ Space, type “Terminal”).
  2. Paste (⌘ V) and press Return.
  3. Open Tidy Sloth from Applications, any time.
